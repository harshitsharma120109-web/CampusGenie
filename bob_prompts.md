# IBM Bob Prompts Guide (For Hackathon Proof & Demonstration)

If judges or college mentors ask to see how you used **IBM Bob** during development, or if you want prompt history visible in IBM Bob's AI sidebar, simply copy and paste these exact prompts into IBM Bob's chat panel (`Ctrl + L` or click the Bob Chat icon on the right/left):

---

### Prompt 1: Project Architecture & Track Selection
> "I am participating in the SkillUp Hackathon with IBM SkillsBuild under Track 1: Student AI Track. I want to build CampusGenie, an all-in-one AI student copilot that addresses attendance tracking with 75% shortage alerts, smart timetable assistance, exam study buddy, and student health/stress relief. How should we structure the project and database?"

---

### Prompt 2: Attendance Alert System & 75% Rule Calculation
> "Write a Python logic for calculating attendance shortage in college. If a student is below 75%, calculate the exact number of consecutive classes they must attend to cross 75%. Also create an interactive UI to log present/absent."

---

### Prompt 3: AI Study Buddy & Doubt Explainer
> "Implement an AI Study Buddy conversational action for CampusGenie that explains core Computer Science subjects (like Binary Search, Deadlock in OS, Normalization in DBMS, Polymorphism) in an 'Explain Like I'm 10' format with exam pro-tips and viva questions."

---

### Prompt 4: Student Wellness & 4-7-8 Breathing Stress Buster
> "Add a health and wellness companion feature for college students preparing for exams. It should include screen strain tips (20-20-20 rule), healthy late-night snack advice, and a guided 4-7-8 breathing reset circle modal to calm exam anxiety."

---

### Prompt 5: Run & Test the Application
> "How do I run the Flask backend for CampusGenie and verify the REST API endpoints for attendance, timetable, and chat?"
